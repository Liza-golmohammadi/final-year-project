Speech Biomarkers (Literature)
Acoustic Features — Task 1
  • Jitter: Pitch variation cycle-to-cycle
  • Shimmer: Amplitude variation
  • HNR: Harmonic-to-noise ratio
  • RPDE: Recurrence period density entropy
  • DFA: Detrended fluctuation analysis
Temporal Features — Task 2
  • Syllable rate (syllables/second)
  • Articulation precision index
  • Rhythm regularity coefficient
Prosodic Features — Task 3
  • Speaking rate (words/minute)
  • Pause duration and frequency
  • Pitch variability (F0 range)
